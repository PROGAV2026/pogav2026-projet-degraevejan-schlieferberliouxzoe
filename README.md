# PROJET ZINZIN — Cle du Vaisseau 🚀
> *A la recherche de la clé perdue à bord du vaisseau* 
## Description
Dans le cadre de notre projet en programmation avancée, on a eu l'opportunité de concevoir un jeu en C#, dans le terminal. 
# METTRE UN VISUEL JEU FINAL

##  HISTOIRE  
> Un **ZINZIN** est perdu dans un vaisseau de **10 étages** et doit pouvoir en trouvant la clé sortir du vaisseau en **10 minutes** ;)

### OBJECTIFS
1. Explorer les étages du vaisseau
2. Trouver la clé cachée dans un module
3. Revenir au bon module de pilotage

## 🛸 ORGANISATION DU VAISSEAU 
> Le jeu integre différent élèments : étages / modules
### Les etages 
Le vaisseau est composé de **trois** types d'étages : 
* 🖥️ Poste de pilotage
* ⚙️ Salle machine
* 🛏️ Lieu de vie

### Les modules 
Chaque étage contient 4 **modules** différents parmis ces modules : 
- 🔵 **Téléportation Départ** 
- 🔴 **Téléportation Arrivée**
- 📦 **Coffre**
- 🛌 **Couchette**
- ☢️ **Moteur**
- 🕹️ **Pilotage**

>Ce sont des élèments avec lequel le **ZINZIN** peut avoir des intéractions.

## Rendu Terminal 
Pour le rendu terminal nous avons chercher longtemps comment faire au mieux l'affichage console. Au premier semestre, nous avions été beaucoup frustré de l'aspect du terminal. Nous avons trouvé une librairie qui permet de découper les fentre en plusieurs panneaux pour l'affichage du jeu ce qui nous a permis de simplifié l'affichage en lui meme. 

Lien de la documentatuion : [Spectre.Console](https://spectreconsole.net/)
